# BBong Capture (뽕캡처)

<img width="2336" height="1744" alt="Image" src="https://github.com/user-attachments/assets/eb081109-9483-4614-bd85-09160d52edc2" />

Windows용 캡처 앱입니다.
우리 집 강아지 짬뽕이가 만든 앱입니다. 어떤 특정 앱과 비슷한 느낌을 받으셨으면 기분 탓일 겁니다.

화면 오른쪽 아래 **트레이(작업 표시줄 시계 옆) 아이콘**으로 실행되고, **단축키**로 언제든 캡처할 수 있습니다.

## 1. 설치와 실행

**Python이나 다른 프로그램을 따로 설치할 필요가 없습니다.**

1. [Releases](https://github.com/Captain-Kim/BBong-Capture/releases) 페이지에서 **`BBongCapture-Setup.exe`** 를 내려받습니다.

또는 아래 설치 링크를 클릭하세요.

- 실행하면 화면 오른쪽 아래 **트레이**(시계 옆, 안 보이면 `^` 화살표 안)에 아이콘이 생깁니다.

### 개발자 (직접 빌드하기)
Python 3.12 이상이 필요합니다.

| 하고 싶은 일      | 방법                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------ |
| 소스로 바로 실행  | `pip install -r requirements.txt` 후 `run.bat` 더블클릭 (오류 확인은 `run_debug.bat`)                              |
| 배포용 exe 만들기 | `build.bat` 더블클릭 → `dist\BBongCapture\BBongCapture.exe` 생성 (폴더째 배포)                                     |
| 설치 파일 만들기  | [Inno Setup 6](https://jrsoftware.org/isdl.php) 을 설치한 뒤 `build.bat` 실행 → `dist\BBongCapture-Setup.exe` 생성 |

- 설치 파일 설정은 `installer\BBongCapture.iss` 에 있습니다. (버전, 설치 경로, 바로가기 등)
- 버전을 올릴 때는 `installer\BBongCapture.iss` 맨 위의 `AppVer` 를 바꾸세요.
- 같은 프로그램을 다시 실행하면 **이전에 켜져 있던 것은 자동으로 종료**되고 새 것으로 바뀝니다. 아이콘이 두 개 생길 걱정은 하지 않아도 됩니다.

## 2. 처음 시작하기 (3분 요약)

1. `Ctrl + Shift + 4` 를 누릅니다. 화면이 살짝 멈추고 십자선이 나옵니다.
2. 찍고 싶은 부분을 마우스로 **끌어서** 선택합니다. 손을 떼면 캡처가 끝납니다.
3. 이미지가 **클립보드에 자동 복사**됩니다. 카톡, 문서, 채팅창에 `Ctrl + V` 로 바로 붙여 넣으세요.
4. 화면 구석에 작은 미리보기 카드(퀵 액세스)가 뜹니다. 여기서 **복사 / 저장 / 편집 / 고정**을 고를 수 있습니다.
5. 꾸미고 싶으면 카드의 **편집**을 누릅니다. 화살표, 글씨, 모자이크 등을 넣을 수 있습니다.

> 파일은 **자동으로 저장되지 않습니다.** 보관하고 싶으면 퀵 액세스 카드의 **저장**을 누르거나 편집기에서 `Ctrl + S` 를 누르세요.
> 매번 자동 저장하고 싶다면 환경설정 > 일반에서 "캡처할 때마다 저장 위치에 자동 저장"을 켜면 됩니다.

## 3. 단축키 한눈에 보기

모든 단축키는 **환경설정 > 단축키** 에서 바꿀 수 있습니다. 칸을 비우면 해당 단축키가 꺼집니다.

| 기능                              | 기본 단축키                                   |
| --------------------------------- | --------------------------------------------- |
| 올인원 (모든 캡처 모드를 한 줄에) | `Ctrl+Shift+1` (또는 트레이 아이콘 왼쪽 클릭) |
| 텍스트 캡처 (OCR)                 | `Ctrl+Shift+2`                                |
| 전체 화면 캡처                    | `Ctrl+Shift+3`                                |
| 영역 캡처                         | `Ctrl+Shift+4`                                |
| 창 캡처                           | `Ctrl+Shift+5`                                |
| 스크롤 캡처                       | `Ctrl+Shift+6`                                |
| 화면 녹화 (MP4)                   | `Ctrl+Shift+7`                                |
| GIF 녹화                          | `Ctrl+Shift+8`                                |
| 이전 영역 다시 캡처               | `Ctrl+Shift+9`                                |
| 캡처 기록 열기                    | `Ctrl+Shift+H`                                |
| 닫은 퀵 액세스 카드 복원          | `Ctrl+Shift+0`                                |
| 퀵 액세스 카드 숨기기 / 보이기    | `Ctrl+Shift+-`                                |
| 고정 화면 잠금 / 해제             | `Ctrl+Shift+L`                                |

다른 프로그램이 같은 단축키를 쓰고 있으면 시작할 때 알림이 뜹니다. 그때는 단축키를 바꿔 주세요.

## 4. 캡처하는 방법

### 4-1. 영역 캡처 `Ctrl+Shift+4`
원하는 사각형 영역만 찍습니다. 가장 많이 쓰는 기능입니다.

- 마우스를 **끌어서** 영역을 정하고 손을 떼면 완료됩니다.
- 화면에 **십자선**과 **돋보기**(좌표, 색상값 표시), 선택한 **크기(px)** 가 나옵니다.
- 끌지 않고 **클릭만 하면** 마우스 아래 있는 창이 통째로 선택됩니다.
- 끄는 동안 `Space` 를 누르고 있으면 선택 영역을 **이동**할 수 있습니다.
- `Shift` 를 누르고 끌면 **정사각형**이 됩니다.
- `Enter` 로 확정, `Esc` 로 취소합니다.
- 십자선, 돋보기, 화면 정지는 트레이 우클릭 > **캡처 옵션** 에서 켜고 끌 수 있습니다.
  - **화면 정지**를 끄면 영상이나 애니메이션처럼 **움직이는 화면**도 찍을 수 있습니다.

### 4-2. 창 캡처 `Ctrl+Shift+5`
창 하나를 골라 깔끔하게 찍습니다. 마우스를 창 위에 올리고 클릭하세요.

트레이 > 캡처 옵션에서 아래 효과를 고를 수 있습니다.
- **모서리 둥글게 (투명)**: 창 모서리가 둥글게 잘리고 바깥은 투명해집니다.
- **그림자**: 창 아래에 그림자가 생깁니다.
- **배경 입히기**: 편집기에서 마지막에 쓴 배경(색, 그라데이션 등)을 자동으로 입힙니다.

### 4-3. 전체 화면 캡처 `Ctrl+Shift+3`
모니터 화면 전체를 찍습니다. 마우스가 있는 모니터가 찍힙니다.

**타이머 캡처**: 트레이 우클릭 > **타이머 전체 화면 캡처** > 3초 / 5초 / 10초.
메뉴가 열려 있어야 찍히는 장면을 준비할 때 편리합니다.

### 4-4. 스크롤 캡처 `Ctrl+Shift+6`
웹페이지, 채팅, 긴 문서처럼 **한 화면에 다 안 담기는 내용**을 이어 붙여 한 장으로 만듭니다.

1. 단축키를 누르고 스크롤할 영역을 선택합니다.
2. 프로그램이 **자동으로 스크롤하면서** 찍어 이어 붙입니다.
3. 영역 옆의 **작은 미리보기 창**에서 지금까지 몇 장이 이어졌는지 볼 수 있습니다.
4. 끝까지 내려가면 자동으로 끝납니다. 중간에 끝내고 싶으면 **완료** 버튼을 누르세요.

팁
- 스크롤되는 영역(웹 페이지 본문 등)을 선택해야 합니다.
- 세로로 안 움직이면 자동으로 **가로 스크롤**을 시도합니다.
- 캡처하는 동안 마우스를 움직이지 마세요.

### 4-5. 올인원 `Ctrl+Shift+1`

<img width="1029" height="137" alt="Image" src="https://github.com/user-attachments/assets/c32d3f11-911c-4d33-9228-2da26d3ade2f" />

화면에 **캡처 도구 모음 한 줄**이 뜹니다. 단축키가 기억나지 않을 때 편합니다. 트레이 아이콘을 **왼쪽 클릭**해도 열립니다.

- **영역 / 창 / 전체 화면 / 스크롤 / 텍스트 / 녹화 / GIF** 를 버튼으로 고릅니다.
- **크기** 칸에 가로 × 세로를 직접 입력하면 정확한 크기로 찍을 수 있습니다. ("자동"이면 마음대로)
- **비율 고정**: 1:1, 4:3, 3:2, 16:9, 9:16, 2:1 중에서 고르면 그 비율로 선택됩니다.
- **이전 영역** 버튼: 방금 찍은 영역을 그대로 다시 불러옵니다.

### 4-6. 이전 영역 다시 캡처 `Ctrl+Shift+9`
같은 자리를 반복해서 찍을 때(변화 비교 등) 편합니다. 영역을 다시 고르지 않아도 됩니다.

### 4-7. 텍스트 캡처 (OCR) `Ctrl+Shift+2`
이미지 속 **글자를 텍스트로 변환**합니다. 영역을 선택하면 글자가 **클립보드에 복사**되고 알림이 뜹니다. 그냥 `Ctrl + V` 로 붙여 넣으면 됩니다. (Windows 기본 OCR 사용, 글자를 못 찾으면 그렇게 알려 줍니다.)

### 4-8. 화면 녹화 `Ctrl+Shift+7` / GIF 녹화 `Ctrl+Shift+8`
영역을 고르면 카운트다운(기본 3초) 후 녹화가 시작됩니다.

- 녹화 바에서 **일시정지**, **중지 및 저장** 을 할 수 있습니다.
- 녹화 파일은 저장 폴더에 저장되고, 퀵 액세스 카드에서 **열기 / 폴더 / 삭제 / 복사** 할 수 있습니다.
- 환경설정 > 녹화에서 **FPS, 마우스 커서 표시, 클릭 강조, 카운트다운** 을 바꿀 수 있습니다.

### 4-9. 클립보드 이미지 다루기
다른 곳에서 복사한 이미지도 바로 쓸 수 있습니다. 트레이 우클릭 메뉴에서:
- **클립보드 이미지 편집**: 편집기에서 열어 꾸밉니다.
- **클립보드 이미지 고정**: 화면 위에 띄워 둡니다. (6장 참고)

## 5. 캡처 직후: 퀵 액세스 카드

캡처하면 화면 구석(기본: 왼쪽 아래)에 **미리보기 카드**가 나타납니다. 카드에 마우스를 올리면 버튼이 보입니다.

| 버튼            | 하는 일                                      |
| --------------- | -------------------------------------------- |
| **복사**        | 이미지를 클립보드에 복사하고 카드를 닫습니다 |
| **저장**        | 원하는 위치와 이름으로 저장합니다            |
| **편집**        | 편집기에서 열어 꾸밉니다                     |
| **고정**        | 이미지를 화면 위에 띄워 둡니다               |
| 오른쪽 위 **⋯** | 파일 경로 복사, 폴더 열기 등 추가 메뉴       |
| 왼쪽 위 **×**   | 카드 닫기                                    |

그 밖에 알아두면 좋은 것
- 카드를 **다른 프로그램 창으로 끌어다 놓으면** 그대로 첨부됩니다. (채팅, 이메일, 문서 등)
- 카드를 옆으로 **밀어서(스와이프)** 닫을 수 있습니다.
- 카드에 이미지의 **크기, 형식, 용량** 정보가 표시됩니다.
- 일정 시간이 지나면 **자동으로 닫힙니다.** 남은 시간은 진행 막대로 보입니다.
- 실수로 닫았다면 `Ctrl+Shift+0` 으로 **복원**하고, `Ctrl+Shift+-` 로 카드를 **숨기거나 다시 보이게** 할 수 있습니다.
- 위치(4개 모서리), 크기(작게/보통/크게), 자동 닫기 시간은 트레이 > **퀵 액세스 오버레이** 또는 환경설정에서 바꿉니다.

## 6. 이미지 편집기

캡처한 이미지에 설명을 달고 가리고 꾸미는 창입니다. 카드의 **편집** 버튼이나 트레이의 **클립보드 이미지 편집** 으로 엽니다.

### 6-1. 화면 구성
- **맨 위 왼쪽**: 도구 모음 (선택, 크롭, 화살표, 선, 사각형, 원, 펜, 형광펜, 텍스트, 번호, 스포트라이트, 모자이크, 블러)
- **맨 위 오른쪽**: 실행 취소 / 다시 실행, 회전, 반전, 크기 조정, 이미지 삽입, 화면에 고정, 복사, 저장, 더보기(⋯), **완료**
- **가운데 줄**: 선택한 도구의 옵션 (색상, 굵기 등 — 도구마다 필요한 것만 나타납니다)
- **아래**: 이미지 크기, **배경** 버튼, 확대/축소 등

### 6-2. 도구 사용법

| 도구         | 단축키 | 사용법                                                                                |
| ------------ | ------ | ------------------------------------------------------------------------------------- |
| 선택 / 이동  | `V`    | 항목을 클릭해 선택하고 끌어서 옮깁니다. 모서리 핸들로 크기를 바꿉니다                 |
| 크롭         | `C`    | 남길 부분을 정하고 `Enter` 로 확정. 비율 고정 가능, 가장자리·중앙에 자석처럼 붙습니다 |
| 화살표       | `A`    | 끌어서 그립니다. 모양 4종: 테이퍼(끝이 뾰족), 라인, 곡선, 양방향                      |
| 선           | `L`    | 끌어서 직선을 그립니다                                                                |
| 사각형       | `R`    | 끌어서 그립니다. **채우기**(속을 칠함), **둥글게**(모서리 둥글게) 옵션                |
| 원           | `O`    | 끌어서 그립니다. 채우기 옵션                                                          |
| 펜           | `P`    | 자유롭게 그립니다. 삐뚤빼뚤한 선은 자동으로 부드럽게 다듬어 줍니다                    |
| 형광펜       | `H`    | 글자 위를 긋습니다. 글자 줄 높이를 자동으로 맞춰 줍니다                               |
| 텍스트       | `T`    | 이미지를 클릭하고 글자를 입력합니다. 스타일 7종 (아래)                                |
| 번호         | `N`    | 클릭할 때마다 1, 2, 3… 번호표를 붙입니다. 순서 설명에 좋습니다                        |
| 스포트라이트 | `S`    | 영역을 끌면 **그 부분만 밝게** 남기고 나머지를 어둡게 합니다                          |
| 모자이크     | `X`    | 영역을 끌어 가립니다. 랜덤 노이즈가 섞여 복원하기 어렵습니다                          |
| 블러         | `B`    | 영역을 흐리게 가립니다. **부드럽게** / **보안**(더 강하게) 중 선택                    |

- **텍스트 스타일 7종**: 기본, 굵게, 외곽선, 배경 상자, 라운드 라벨, 그림자, 형광 배경. 폰트도 고를 수 있습니다.
- 텍스트를 쓸 때 슬라이더는 **글자 크기**, 다른 도구에서는 **선 굵기** 입니다.
- 개인정보(이름, 전화번호, 계정 등)를 가릴 때는 **모자이크나 블러(보안)** 를 쓰세요.
- `Shift` 를 누르고 그리면 선·화살표는 **각도(수평/수직/45도)** 가 고정되고, 사각형·원은 **정사각형/정원** 이 됩니다.

### 6-3. 색상
- 팔레트에서 색을 고릅니다.
- **스포이드**로 화면 어디서든 색을 뽑을 수 있습니다.
- 자주 쓰는 색은 **즐겨찾기**로 저장해 둘 수 있습니다.
- 이미 그린 항목을 선택한 상태에서 색을 고르면 **그 항목의 색이 바뀝니다.**

### 6-4. 수정하고 되돌리기
- 항목을 선택하고 **방향키** 로 미세하게 옮길 수 있습니다.
- `Del` 로 선택한 항목을 지웁니다.
- `Ctrl + Z` 실행 취소, `Ctrl + Y` 다시 실행.

### 6-5. 이미지 자체를 바꾸기 (위쪽 오른쪽 버튼)
- **회전**(왼쪽/오른쪽), **좌우 반전**, **상하 반전**
- **크기 조정**: 가로·세로 크기를 숫자로 바꿉니다.
- **이미지 삽입**: 다른 스크린샷을 추가해 **여러 장을 한 장으로 합칩니다.** 버튼 말고도 이미지 파일을 **끌어다 놓거나**, `Ctrl + V` 로 붙여 넣어도 됩니다.

### 6-6. 배경 꾸미기 ("배경" 버튼)
스크린샷을 예쁜 배경 위에 올려 발표 자료나 SNS용 이미지로 만듭니다.
- **20가지 기본 배경**, 단색, **내 이미지**, 바탕화면, 투명 중에서 선택
- **여백**, **이미지 위치(9방향)**, **비율**(1:1, 4:3, 16:9 등), **모서리 둥글기**, **그림자**
- **자동 균형**: 여백을 알아서 맞춰 줍니다
- **프리셋 저장 / 불러오기**: 마음에 드는 설정을 저장해 두고 다시 씁니다

### 6-7. 내보내기와 저장

## 7. 고정 스크린샷 (화면에 띄워 두기)

캡처한 이미지를 **항상 맨 위에** 띄워 두고 참고하면서 작업할 수 있습니다. 퀵 액세스 카드의 **고정**, 편집기의 고정 버튼, 트레이의 **클립보드 이미지 고정** 으로 만듭니다.

- 끌어서 위치를 옮깁니다.
- **마우스 휠**: 크기 조절 / `Ctrl + 휠`: 투명도 조절
- **방향키**: 위치를 아주 조금씩 이동 (`Shift` 를 같이 누르면 10px씩)
- `+` / `-` 키로도 크기를 바꿀 수 있습니다.
- `Ctrl + C` 로 복사, `Esc` 로 닫기.
- **우클릭 메뉴**: 복사, 다른 이름으로 저장, 편집, 크기, 투명도, 잠금 모드, 닫기
- **잠금 모드**: 이미지가 **클릭을 통과**시켜 아래 창을 그대로 조작할 수 있습니다. 해제하려면 `Ctrl + Shift + L` 을 누르세요.

## 11. 파일은 어디에 저장되나요?

- **캡처 직후**: 자동 저장이 꺼져 있으면 저장 폴더에는 아무 파일도 생기지 않습니다. (작업용 임시 파일은 하루가 지나면 자동으로 삭제됩니다.)
- **저장 버튼을 누르면** 선택한 위치에 저장됩니다. 자동 저장을 켠 경우에는 저장 폴더에 `BBongCapture 2026-01-01 at 12.00.00.png` 같은 이름으로 쌓입니다.
- **녹화 파일**은 항상 저장 폴더에 저장됩니다.
- **캡처 기록**은 설정과 함께 `%APPDATA%\BBongCapture` 폴더에 30일간 보관됩니다.

## 12. 자주 묻는 질문

**Q. 단축키가 안 먹어요.**
다른 프로그램이 같은 단축키를 쓰고 있을 수 있습니다. 환경설정 > 단축키에서 바꿔 보세요. 트레이 아이콘이 두 개라면 이전에 켜진 것이 남아 있는 것이니, 하나를 종료하세요.

**Q. 캡처했는데 파일이 없어요.**
기본 설정에서는 자동 저장을 하지 않습니다. 퀵 액세스 카드나 편집기에서 **저장**을 누르거나, 환경설정에서 자동 저장을 켜세요. 클립보드에는 항상 복사되어 있습니다. (끄지 않았다면)

**Q. 스크롤 캡처가 중간에 끝나요.**
스크롤되는 영역을 정확히 선택했는지, 캡처 중 마우스를 움직이지 않았는지 확인하세요. 페이지가 로딩 중이거나 화면이 계속 바뀌는 곳은 이어 붙이기가 어려울 수 있습니다.

**Q. 퀵 액세스 카드를 닫아 버렸어요.**
`Ctrl+Shift+0` 으로 복원하거나, 캡처 기록(`Ctrl+Shift+H`)에서 다시 꺼내세요.

**Q. 마우스 커서가 사진에 안 찍혀요.**
스크린샷에는 마우스 포인터가 포함되지 않습니다. (녹화는 환경설정에서 커서 표시를 켤 수 있습니다.)

**Q. 문제가 생겼는데 원인을 모르겠어요.**
`%APPDATA%\BBongCapture` 폴더의 `error.log`(오류), `debug.log`를 확인해 보세요. 소스로 실행하는 경우 `run_debug.bat` 으로 실행하면 콘솔에 오류가 보입니다.
